# Rollout to the other 25 drills (Stage 3)

Every drill now follows `STANDARD.md`: the full coaching structure, no named players or coaches, no unsourced
statistics, a note on where golfers differ, a slow rehearsal and a held key position, a clear wrong version, and (where
it makes sense) a real-speed rep. What changed in each:

| Drill | Main changes |
|---|---|
| Hand-hang distance | Side-on close camera; plumb line from the shoulder; two wrong versions (too far, too close) standing visibly further from or nearer the ball |
| Spine-tilt check | Demo rebuilt to match the text: club held upright down the middle, tilt until it points at the lead knee (new upright-club arm pose); hip-slide wrong version; then a driver swing staying behind the ball |
| Chair drill | Coaching rewritten; real-speed rep added; statistic removed |
| Water bottle | Now the range, full-speed partner of the chair drill and about the trail leg; closer camera on the feet; badge moved to impact; heel-spin wrong version added |
| Head against the wall | Dip and stand-up wrong versions; slow turns |
| Umbrella | Rewritten; real-speed rep |
| Shadow drill | Closer camera; steps no longer duplicate each other |
| Step-back setup | Demo rebuilt: feet together, then only the trail foot steps back (it now actually steps); leaning-ahead wrong version with plumb lines |
| Trail shoulder behind your head | Shoulder-line reference; statistic removed |
| Trail pocket back | New identity: an overhead view of the hip line against the shoulder line, with a "hips locked, arms only" wrong version |
| Thumb-grip top check | Opens on a close-up of the hands; half-way pose fixed; arm-bent wrong version drawn with lines |
| Lead-arm-only swings | Chicken-wing wrong version made visible (from the front, with arm lines) |
| Stop at the top | New identity: the pause, then the lower body starts down; casting wrong version; a second rep with a shorter pause |
| 3-to-1 tempo count | Renamed (the old name was a commercial programme's); a rushed 1-to-1 rep for comparison; claims about named players removed |
| Feet-together swings | Falling-back wrong version; switches to a normal stance at the end |
| Stick over the ball | Stick fixed: it now angles up over the ball toward the trail shoulder; over-the-top wrong version; real-speed rep |
| Headcover outside the ball | Overhead camera; out-to-in wrong version |
| Two-ball gate | Overhead close-up so the balls are visible; gate line; out-to-in wrong version |
| Glove under the trail arm | Reframed as connection for shorter swings (not a full-swing rule); disconnected wrong version |
| Trail heel down | Early heel and hips-toward-ball wrong version; real-speed rep |
| Two sticks for the weight shift | Rewritten; real-speed rep |
| Belt-loop click | Hips-stalled wrong version; statistic removed |
| Split-hand pump | Opens on a close-up so the split grip is visible; chicken-wing wrong version from the front |
| Doorway head check | Rewritten; slower |
| Hold the finish | Rewritten; claims about named players removed |

Near-duplicates were given distinct jobs rather than removed: the chair (hips, at home, slow) and the bottle (trail leg,
on the range, at speed); the stick over the ball (plane at the start of the downswing), the headcover (path just before
the ball), the two-ball gate (clubhead path and strike) and the glove (connection); the wall (head height), the doorway
(head toward the target) and the shadow (sway, outdoors); stop at the top (sequence) and the tempo count (rhythm).

## Library

- Category chips (Setup, Backswing, Transition, Downswing, Impact, Finish) replace the swing-area chips; "For my
  swing" still comes first after an analysis.
- Each card shows what the drill improves, the faults it fixes, where, how long, the level and the kit, and the list
  shows how many drills match.
